HELPFUL CHARITY WEBSITE

Pages:
- index.html: Home
- about.html: About the charity
- programs.html: Charity programs
- get-involved.html: Volunteer and donation options
- contact.html: Contact form

How to run:
1. Extract the ZIP file.
2. Open index.html in a browser, or use VS Code with the Live Server extension.
3. Keep the css and js folders beside the HTML files.

Notes:
- This is a static front-end demo. The contact form shows a confirmation but does not send messages.
- Replace hello@helpful.org, sample text, and stock photos with the charity's real information.
- The photos and Google Fonts load from the internet.
